# Multimodal Sources (`sources/multimodal/`)

> Speech recognition (ASR), Text-to-Speech (TTS), Document AI OCR, and Vision-Language datasets.

---

## 📁 Subcategories

1. **`asr/`**: Speech audio recordings paired with Devanagari text transcriptions (`himalaya-ai/nep-voice-tts-compilation`, `ilprl-docse/Nwacha_Muna_A_Newari_ASR_Dataset`).
2. **`ocr/`**: Document AI, character grapheme recognition (`himalaya-ai/devanagari_ocr_graphemes`, `himalaya-ai/nepalipixel-synthetic-ocr-benchmark`).
3. **`tts/`**: 55-hour studio recordings and multi-speaker TTS alignments (`chhatramani/Nepali_TTS_55hrs`).
4. **`vision/`**: Image captioning and Visual Question Answering (VQA).
