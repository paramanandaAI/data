# Other Data (Factual & External Domain Datasets)

This directory stores pre-existing factual noisy-clean parallel datasets across various domain tasks.

## Subdirectories:

- `ocr/`: RoundTripOCR Nepali dataset (`cfilt/RoundTripOCR-nepali`) containing OCR scan outputs and ground truth text.
- `gec/`: Grammatical Error Correction datasets (e.g. NepBERTa GEC synthetic and annotated pairs).
- `translation/`: Trilingual parallel corpora (e.g. CLE / IndicNLP English-Nepali-Urdu triplets).
