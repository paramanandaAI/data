# Supervised Fine-Tuning Sources (`sources/sft/`)

> Alpaca, ShareGPT, multi-turn dialogues, domain Q&A (Legal, Health, Agriculture, Commerce), Translation, Summarization, and GEC datasets.

---

## 📁 Subcategories

1. **`instruction/`**: General instruction tuning datasets (`nepali_alpaca`, `dineshkarki_sft`, `nepali_hermes_function_calling`).
2. **`domain/`**:
   - `legal/`: 44 Acts, Supreme Court judgments, Civil Code Q&A.
   - `healthcare/`: Clinical conversations, medical advice Q&A.
   - `agriculture/`: Crop recommendation, soil diagnostics, pest management.
   - `commerce/`: Retail banking customer care, NEPSE share market.
3. **`gec/`**: Grammatical error correction, error detection, OCR post-correction.
4. **`translation/`**: English-Nepali parallel MT, Romanized-to-Devanagari transliteration, Newari/Tamang parallel data.
5. **`summarization/`**: BBC Nepali XL-Sum, multi-sentence news summaries.
