## 🇳🇵 8. Nepali HuggingFace Ecosystem — Quick Reference (datasets part)

### 8.1 Nepali Datasets on HuggingFace (564+)

**Pretraining Corpora (136 datasets):**
- [`Sakonii/nepalitext-language-model-dataset`](https://huggingface.co/datasets/Sakonii/nepalitext-language-model-dataset) — 13.4M text passages
- [`himalaya-ai/nepali-corpus-compile`](https://huggingface.co/datasets/himalaya-ai/nepali-corpus-compile) — 31.3M deduplicated sentences
- [`Basanta55/cc100-nepali-strictly-cleaned-devanagari-only`](https://huggingface.co/datasets/Basanta55/cc100-nepali-strictly-cleaned-devanagari-only) — 1.29M filtered CC-100
- [`raygx/Nepali-Extended-Text-Corpus`](https://huggingface.co/datasets/raygx/Nepali-Extended-Text-Corpus) — 14.6M rows
- [`tonibirat/neBrahma-Nepali-Pretrain-Corpus`](https://huggingface.co/datasets/tonibirat/neBrahma-Nepali-Pretrain-Corpus) — 20.3M rows

**SFT & Instruction Datasets:**
- [`ibibek/Nepali-Alpaca`](https://huggingface.co/datasets/ibibek/Nepali) — Nepali instruction tuning
- [`manojbaniya/ift-nepali-v5`](https://huggingface.co/datasets/manojbaniya/ift-nepali-v5) — IFT dataset
- [`Aananda-giri/nepali_llm_datasets`](https://huggingface.co/datasets/Aananda-giri/nepali_llm_datasets) — 1.85M rows

**Sentiment & Classification:**
- [`mteb/NepaliNewsClassification`](https://huggingface.co/datasets/mteb/NepaliNewsClassification) — MTEB benchmark
- [`Shubhaaa3399/nepalisent`](https://huggingface.co/datasets/Shubhaaa3399/nepalisent) — Sentiment analysis
