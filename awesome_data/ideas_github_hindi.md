# Hindi & Indic Open-Source NLP, Text Corpora & LLM Catalog

A detailed, exhaustive open-source catalog of Hindi and Indic Natural Language Processing (NLP) resources, machine translation engines, transliterators, tokenizers, domain QA datasets, OCR tools, and LLM evaluation frameworks.

---

## 🔤 1. Tokenization, BPE, Embeddings & Text Processing

- **[Aasim-k/hindi-bpe](https://github.com/Aasim-k/hindi-bpe)** — Byte Pair Encoding (BPE) tokenizer trained on Hindi text with encoder/decoder binaries.
- **[shubhamdawande/Extending-Llama-3-Tokenizer-Hindi](https://github.com/shubhamdawande/Extending-Llama-3-Tokenizer-Hindi)** — Extending Llama 3 tiktoken-based tokenizer on Hindi and regional Indic scripts.
- **[ajstyle007/HindiGPT-Tokenizer-BPE-DataPrep](https://github.com/ajstyle007/HindiGPT-Tokenizer-BPE-DataPrep)** — SentencePiece BPE tokenizer trained from scratch on large-scale clean Hindi corpora with binary pre-tokenization.
- **[code0era/Hindi-Word2Vec-Analysis](https://github.com/code0era/Hindi-Word2Vec-Analysis)** — Trained Hindi Word2Vec model on 5M+ words (617k vocabulary) with t-SNE evaluation.
- **[Praggie/Hindi-Words-Importance-Dataset](https://github.com/Praggie/Hindi-Words-Importance-Dataset)** — Repository of 14,000 Hindi words with Inverse Document Frequency (IDF) weights.
- **[ruvimals/Dataset-Hindi-WordSim353](https://github.com/ruvimals/Dataset-Hindi-WordSim353)** — Word similarity evaluation dataset for the Hindi language (Hindi adaptation of WordSim353).
- **[taranjeet/hindi-tokenizer](https://github.com/taranjeet/hindi-tokenizer)** — Tokenizer and stemmer for the Hindi language.
- **[aniket-2003-das/Hindi-Lemmatizer](https://github.com/aniket-2003-das/Hindi-Lemmatizer)** — Tool to identify the root lemma form of Hindi words.
- **[srvCodes/morph_analyzer](https://github.com/srvCodes/morph_analyzer)** — Keras-based multi-tasking morphological analyzer for Hindi and Urdu.
- **[Desivocal/Hindi-Text-Processor](https://github.com/Desivocal/Hindi-Text-Processor)** — Text normalization, cleaning, and preparation toolkit for Hindi NLP.
