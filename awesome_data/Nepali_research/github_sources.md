# Nepali Open-Source Data & Datasets Catalog

A comprehensive catalog of open-source datasets, scrapers, corpora, and data engineering projects specifically for the Nepali language and Devanagari script, compiled from open-source GitHub listings.

---

## 📚 1. Text Corpora & News Datasets

- **[superryeti/Daraz-online-shopping-data-corpus](https://github.com/superryeti/Daraz-online-shopping-data-corpus)** — E-commerce data corpus scraped from `daraz.com.np`.
- **[shekharkoirala/nepali_wikipedia_curpos](https://github.com/shekharkoirala/nepali_wikipedia_curpos)** — Nepali Wikipedia text corpus scraper and raw dumps.
- **[ashokbasnet/nepali-news-dataset](https://github.com/ashokbasnet/nepali-news-dataset)** — Nepali news dataset covering 10 categories from 5 popular portals.
- **[Srmaraghu/news-data-pipeline](https://github.com/Srmaraghu/news-data-pipeline)** — Production ETL pipeline scraping 12+ Nepali news sources and NEPSE stock data.
- **[thegauravgiri/newsapi](https://github.com/thegauravgiri/newsapi)** — Free open-source news aggregation service scraping top Nepali news portals.
- **[12-Twelvve/poem_dataset](https://github.com/12-Twelvve/poem_dataset)** — Nepali poem dataset scraped from various literary portals.
- **[Utshav-paudel/Nepali-Media-Content](https://github.com/Utshav-paudel/Nepali-Media-Content)** — Multi-source dataset collected across different news sites in Nepal.
- **[anurag3345/NepaliCleanedDataset](https://github.com/anurag3345/NepaliCleanedDataset)** — Cleaned text corpus for language model pre-training.

## 🗣️ 2. Speech, ASR & Audio Corpora

- **[ishworrsubedii/nepali_speech-to-text_datasets](https://github.com/ishworrsubedii/nepali_speech-to-text_datasets)** — Collection of Nepali speech audio recordings and transcriptions.
- **[aatizghimire/nepali-speech-corpus](https://github.com/aatizghimire/nepali-speech-corpus)** — Nepali audio data collection project.
- **[Aadarshttech/nepali-english-codeswitched-whisper](https://github.com/Aadarshttech/nepali-english-codeswitched-whisper)** — Fine-tuning scripts and datasets for adapting Whisper to Nepali-English code-switched speech.
- **[SUBOdhar/audinp](https://github.com/SUBOdhar/audinp)** — Data collector in Python for Nepali language and voice models.
- **[santoshdahal2016/Nepali-Accented-English-Evaluation-Dataset](https://github.com/santoshdahal2016/Nepali-Accented-English-Evaluation-Dataset)** — English speech recorded by speakers from Nepal with rich per-recording metadata.
- **[PragyanSubedi/nepali-speech-dataset-creator](https://github.com/PragyanSubedi/nepali-speech-dataset-creator)** — Audio dataset creator for Nepali speech recognition.
- **[Melina-Singh/Music-Classification](https://github.com/Melina-Singh/Music-Classification)** — Nepali music genre classification using log mel spectrograms.

## 🔄 3. Script Conversion & Transliteration

- **[Shahil050/romanized_nepali_dataset](https://github.com/Shahil050/romanized_nepali_dataset)** — Parallel Romanized Nepali to Devanagari text dataset.
- **[Subu19/Nepali-Roman-Dataset-Generator](https://github.com/Subu19/Nepali-Roman-Dataset-Generator)** — Generator script for Nepali-Romanized dataset creation.
- **[rojanparajuli/Nepali-Romanized-speech-to-text](https://github.com/rojanparajuli/Nepali-Romanized-speech-to-text)** — JSON dataset for Romanized Nepali speech-to-text.
- **[binayachaudari/Nepali-Tamang-MT-Data](https://github.com/binayachaudari/Nepali-Tamang-MT-Data)** — Machine translation parallel corpora for Tamang to Nepali.

## 🏷️ 4. Sentiment & NLP Classification Datasets

- **[Shubhaaa3399/nepalisent](https://github.com/Shubhaaa3399/nepalisent)** — Nepali sentiment analysis using fine-tuned multilingual BERT.
- **[sunil-thapa99/nepali_sentiment_data](https://github.com/sunil-thapa99/nepali_sentiment_data)** — Nepali sentiment classification dataset.
- **[RayGone/Nepali-Sentiment-Analysis-Data](https://github.com/RayGone/Nepali-Sentiment-Analysis-Data)** — Collection of Nepali tweets collected during the 2015 earthquake.
- **[ios-ioe/Nepali-Bias-Language-Dataset](https://github.com/ios-ioe/Nepali-Bias-Language-Dataset)** — Nepali dataset labeled for bias categories (gender, religion, caste, regional, appearance).
- **[nowalab/DanfeNER](https://github.com/nowalab/DanfeNER)** — Named Entity Recognition dataset in Nepali tweets.
- **[SujilDevkota/NepaliCorpus-POS-Tags](https://github.com/SujilDevkota/NepaliCorpus-POS-Tags)** — Nepali POS tagged corpus converted from Nepali-Urdu parallel datasets.

## 📷 5. Multimodal & Vision Datasets

- **[ShubhaPradhan/Nepali-Flickr8k-Dataset](https://github.com/ShubhaPradhan/Nepali-Flickr8k-Dataset)** — Flickr8k image captioning dataset translated into Nepali.
- **[bipeshrajsubedi/Flickr30k_Nepali_Dataset](https://github.com/bipeshrajsubedi/Flickr30k_Nepali_Dataset)** — Flickr30k image captions translated into Nepali.
- **[ishworrsubedii/nepali-vehicles-dataset](https://github.com/ishworrsubedii/nepali-vehicles-dataset)** — Collection of images depicting vehicles in Nepal.
- **[dahalsweekar/Nepali-Handwritten-Dataset-for-Recognition](https://github.com/dahalsweekar/Nepali-Handwritten-Dataset-for-Recognition)** — Cropped images and labels for Nepalese handwritten character recognition.
- **[kshitizregmi/Nepali-Cash-Detection-Recognition](https://github.com/kshitizregmi/Nepali-Cash-Detection-Recognition)** — Nepali cash banknote detection dataset using InceptionV3.
- **[aistudioorg/nepali-keyboard-with-nepali-character-dataset](https://github.com/aistudioorg/nepali-keyboard-with-nepali-character-dataset)** — Nepali keyboard layout and character dataset useful for TTS and NLP.
- **[Alish545/Number-Plate-Project](https://github.com/Alish545/Number-Plate-Project)** — Vehicle number plate detection & recognition using YOLOv8n for Nepalese license plates.

## 🏥 6. Domain Applications & Specialized Utilities

- **[Harman-Bhuju/RapiReport](https://github.com/Harman-Bhuju/RapiReport)** — AI-powered healthcare platform converting raw/handwritten diagnostic test data into bilingual (Nepali/English) reports.
- **[Swoyesh/House_Price_Predictor](https://github.com/Swoyesh/House_Price_Predictor)** — Machine learning web app predicting housing prices in Nepal using Random Forest regression.
- **[ZaddyAI/Sajilo-Khata](https://github.com/ZaddyAI/Sajilo-Khata)** — Automatic income/expense tracking mobile app reading SMS messages from Nepali banks.
- **[tilakpoudel/flutter_todo_with_localization](https://github.com/tilakpoudel/flutter_todo_with_localization_and_local_storage)** — Mobile application featuring live English and Nepali localization.
